
# AI Career Recommendation System

A machine learning project that recommends possible career paths based on skill ratings.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Random Forest
- Streamlit

## Features
- Skill rating sliders
- Top 3 career recommendations
- Downloadable results

## Run the project
Install dependencies:

pip install -r requirements.txt

Launch the application:

streamlit run app.py

## Disclaimer
This project uses a small demonstration dataset. Recommendations are not validated career assessments.
